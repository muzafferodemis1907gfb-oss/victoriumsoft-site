# VictoriumSoft canlı domain kurulumu

Ana alan adı: **https://www.victoriumsoft.site/**

Canlı yapı:
- Domain kayıt firması: Natro
- DNS nameserver: `ns1.vercel-dns.com` / `ns2.vercel-dns.com`
- Hosting / deployment: Vercel
- Kaynak kod: GitHub `muzafferodemis1907gfb-oss/victoriumsoft-site`
- `victoriumsoft.site` Vercel üzerinde `www.victoriumsoft.site` adresine yönlendirilir.

## Önemli
Bu proje artık GitHub Pages custom domain kullanmıyor. Repository köküne `CNAME` dosyası eklemeyin.

GitHub'a yapılan her commit Vercel projesine bağlıysa otomatik olarak yeni deployment oluşturur.

## Güncel SEO / site dosyaları
- `sitemap.xml` canlı `www.victoriumsoft.site` adresini kullanır.
- `robots.txt` sitemap adresini belirtir.
- Canonical ve Open Graph URL'leri canlı domain ile uyumludur.
- HTTPS / SSL Vercel tarafından yönetilir.
